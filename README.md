# 🎵 MELODY – Music Streaming Website

**Feel Every Beat 🎧**

MELODY is a modern and responsive music streaming website designed to provide users with an enjoyable music discovery experience. It allows users to explore popular artists, featured albums, playlists, recently played songs, and trending music through an attractive and user-friendly interface.

🌐 **Live Website:** https://greeshmikachinni-ops.github.io/feel-it-/

---

## ✨ Features

- 🎤 **Popular Artists** – Discover popular singers and music composers.
- 💿 **Featured Albums** – Explore different music collections.
- 🎶 **Playlists** – Enjoy specially curated playlists.
- 🕒 **Recently Played** – View recently played songs.
- 🔥 **Popular Tracks** – Discover trending and popular music.
- 🔍 **Search Bar** – Search for songs, artists, and albums.
- 🎧 **Music Player** – Player section with previous, play, and next controls.
- 📱 **Responsive Design** – User-friendly layout for different screen sizes.

## 🖥️ Website Sections

1. **Home** – Welcome section with the tagline "Feel Every Beat".
2. **Artists** – Displays popular music artists.
3. **Albums** – Showcases featured music albums.
4. **Playlists** – Displays personalized music collections.
5. **Recently Played** – Shows recently played tracks.
6. **Popular Tracks** – Highlights popular music.
7. **Music Player** – Provides music playback controls.

## 🛠️ Technologies Used

- **HTML5** – For webpage structure.
- **CSS3** – For styling, layout, and responsive design.
- **Google Fonts** – For typography.
- **Unsplash** – For visual images.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/greeshmikachinni-ops/feel-it-.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Explore the MELODY music streaming website.
